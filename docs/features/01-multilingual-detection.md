# Feature 01: Multilingual Language Detection

## What It Does
The Multilingual Language Detection module accurately detects whether a student query is written in English (`en`), Hindi (`hi`), Gujarati (`gu`), Hinglish (`hi-Latn`), or Gujlish (`gu-Latn`). It leverages Unicode script range heuristics combined with colloquial transliterated marker n-grams to classify code-mixed college inquiries in under 1 millisecond.

## Files Involved
- `nlp-service/features/language_detector/detector.py`: Core detection engine and transliteration lexicons.
- `nlp-service/features/language_detector/router.py`: FastAPI endpoints guarded by feature flag checking.
- `nlp-service/features/language_detector/tests/test_detector.py`: Unit test suite verifying cross-language accuracy.
- `nlp-service/config/features.json`: Dynamic feature flag (`multilingual_detection`).
- `server/features/chat/chatController.js`: Express.js API gateway router dispatching to NLP service.
- `server/config/features.js`: Server-side feature flag.
- `client/src/features/chat/ChatWindow.jsx`: React chat interface displaying detected dialect badges.
- `data/language_eval_benchmark.json`: Test corpus of 20 realistic collegiate domain inquiries.
- `eval/eval_language_detection.py`: Evaluation and latency benchmarking script.
- `eval/results/01-multilingual-detection.json`: Output metrics for the project resume.

## API Endpoints
### `POST /language/detect` (NLP Service - Port 8000)
- **Request Body**:
  ```json
  {
    "text": "Hostel ma room book karva mate shu document joyiye?"
  }
  ```
- **Response Body**:
  ```json
  {
    "language": "gu-Latn",
    "confidence": 0.93,
    "is_transliterated": true,
    "feature_enabled": true
  }
  ```

### `POST /api/chat/message` (API Gateway - Port 5000)
- **Request Body**:
  ```json
  {
    "query": "College me admission kaise lena hai aur fees kitni hai?"
  }
  ```
- **Response Body**:
  ```json
  {
    "reply": "Response received for: \"College me admission kaise lena hai aur fees kitni hai?\"",
    "detected_language": "hi-Latn",
    "confidence": 0.95,
    "is_transliterated": true,
    "feature_active": true
  }
  ```

## Feature Flag Behavior
- **Flag**: `multilingual_detection` (in `nlp-service/config/features.json` and `server/config/features.js`).
- **When `false`**: NLP endpoint returns baseline fallback `{"language": "en", "confidence": 1.0, "is_transliterated": false, "feature_enabled": false}` without running model classification. Server gracefully routes baseline query without breaking.
- **When `true`**: Full transliterated & native script detection runs with sub-millisecond latency.
