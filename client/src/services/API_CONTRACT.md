# CampusMate API contract

Source read: `server/server.js`, `server/routes/chat.js`, `server/features/f00_history`, `f08_admin`, `f10_feedback`, `f11_analytics`, `f12_cache`, `f13_telegram`, `server/models`, `server/services/nlpClient.js`.

Base URL (dev): `http://localhost:5000`. The Vite dev server proxies `/api` → gateway, so the browser can call the relative path `/api/...`.

Global middleware on `/api/*`: Helmet headers, CORS allow-list (`CORS_ORIGIN`), JSON body limit 100 KB, rate limit **150 requests / 15 min / IP**, latency tracker (chat POSTs only), request logger.

## Authentication & identity

| Mechanism | Where | Details |
|---|---|---|
| Anonymous client identity | `X-Client-Id` request header (or `?clientId=` query for history) | A random ID generated by the frontend and persisted in `localStorage` (`campusmate_client_id`). When unauthenticated in guest mode, scopes conversations. |
| Student & Admin Auth | `Authorization: Bearer <accessJwt>` | Short-lived access JWT (15 min) kept in memory. |
| Refresh Token | Cookie `refreshToken` | `httpOnly`, `SameSite=Lax` cookie storing rotating session token. Reusing revoked/old token invalidates session family. |
| Superadmin Invites | One-time token | 48-hour single-use token sent via `/invite/:token` to onboard new admins. |

### Feature 16: Authentication & Roles Endpoints

#### Student Authentication (`/api/auth`)
- `POST /api/auth/signup`: Body `{ name, email, password, semester?, branch? }`. Enforces `ALLOWED_EMAIL_DOMAINS` and password policy. Returns `{ user, accessToken }` and sets `refreshToken` cookie.
- `POST /api/auth/login`: Body `{ email, password, rememberMe? }`. Rate limited and locks out after 5 failures for 15 mins.
- `POST /api/auth/refresh`: Cookie-based session refresh. Rotates refresh token and returns `{ accessToken, user }`.
- `POST /api/auth/logout`: Revokes active refresh token.
- `POST /api/auth/logout-all`: Bearer authenticated. Revokes all session families for user.
- `GET /api/auth/me`: Bearer authenticated. Returns `{ user }`.
- `PATCH /api/auth/me`: Bearer authenticated. Updates `{ name?, semester?, branch? }`.
- `POST /api/auth/change-password`: Bearer authenticated. Body `{ currentPassword, newPassword }`.
- `GET /api/auth/sessions`: Bearer authenticated. Returns list of active device sessions.
- `DELETE /api/auth/sessions/:familyId`: Bearer authenticated. Revokes specific device session.
- `DELETE /api/auth/me`: Bearer authenticated. Detaches chat history, anonymizes records, and deletes user.
- `POST /api/auth/claim-guest-history`: Bearer authenticated. Body `{ clientId }`. Claims anonymous conversations onto the authenticated user.
- `POST /api/auth/invite/accept`: Body `{ token, password }`. Activates invited admin account.

#### Admin Authentication & Superadmin Team Management (`/api/admin`)
- `POST /api/admin/auth/login`: Body `{ email, password, rememberMe? }`. Restricts access to admin/superadmin roles only.
- `POST /api/admin/team/invites`: Superadmin only. Body `{ name, email, role }`. Generates 48-hour invite token and link.
- `GET /api/admin/team`: Superadmin only. Lists admins, statuses, and last login timestamps.
- `PATCH /api/admin/team/:id`: Superadmin only. Body `{ status }`. Protected against disabling last superadmin.
- `POST /api/admin/team/:id/reset-link`: Superadmin only. Generates single-use password reset link.
- `DELETE /api/admin/team/:id`: Superadmin only. Protected against deleting last superadmin.
- `GET /api/admin/audit`: Superadmin only. Query params: `page`, `limit`, `action`, `actorId`, `targetType`, `startDate`, `endDate`. Returns paginated audit trail.

Legacy fallback admin route `POST /api/admin/login` remains available during migration.

## Backend gaps (UI needs, backend does not provide)

1. **Document detail / chunk listing** — no `GET /api/admin/documents/:id`; chunk details only exist as `chunk_count` on the list.
2. **Admin logout** — JWT is stateless; no revoke endpoint. The client clears the token locally.
3. **Admin profile / settings** — no `GET/PATCH /api/admin/me` or preferences API; profile name/email and language are local-only.
4. **Cache entry listing** — only aggregate stats and a flush call; no keys/values endpoint (the Cache page states this explicitly).
5. **Add unanswered query to review queue** — analytics returns `topUnanswered`, but there is no endpoint to enqueue one as feedback.
6. **Previous-period KPIs / deltas** — overview has no comparison window; deltas are computed client-side from the returned series where possible and omitted otherwise.
7. **Persisted citations** — assistant messages store `sourceDoc` but not citation snippets; reloading a conversation loses citation chips.
8. **Feedback pagination** — queue is capped at 200 and has no cursor; the UI uses client-side pagination.

### Resolved in this step

- **Delete document** — `DELETE /api/admin/documents/:id` added with admin JWT; covered by `server/features/f08_admin/tests/documentDelete.test.js`.
- **Image uploads** — multer now accepts `.png`, `.jpg`, `.jpeg` in addition to `.pdf`, `.docx`, `.txt`. Ingestion is best-effort; scanned images have no OCR guarantee.
- **Cache route protection** — cache stats, invalidation, and latency stats now require a Bearer JWT.
- **Latency series** — `queriesOverTime[]` now includes daily `avgLatencyMs` and `p95LatencyMs`.
- **Original filename** — `Document.original_name` preserves the uploaded filename.
- **Feedback queue default** — `status` now defaults to `all` instead of filtering to pending only.
